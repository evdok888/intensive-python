1) if / elif / else - условные конструкции для ветвления программ
2) вложенный if  - это конструкция иф коорая находится внутри блока кода другого ифа
3) тернарный оператор - сокращеная форма записи внутри блока кода
4) for - цикл для перебора элементов последовательности (списков, строк, диапазонов)
5) while - цикл с предусловием который повторяет выполнение блока кода до тех пор пока указаное условие истино
6) range() - встроенная функция для генерации последовательности чисел
7) break - оператор досрочного выхода из цикла
8) continue - оператор пропуска текущей итерации цикла
9) pass - пустая операция (заглушка)
10) else у циклов - необязатеьный блок крирпый выполняется после нормального завершения цикла, но не выполняется если цикл был прерван
11) вложенные циклы - циклы находящиеся внутри других циклов. Внешний цикл запускается заново для каждой итерации внутреннего цикла
12) блок-схема - графическое представление алгоритма с использованием стандартизированных фигур
13) линейный / развлетвляющийся / цикличкеский алгоритм - три основные структуры алгоритмов:
 -линейный - инструкция выполняется последовательно одна за другой без переходов
 -разветвляющийся - содержит условия который определяют направление выполнения
 -циклический - включает повторение определенных действий несколько раз
