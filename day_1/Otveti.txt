1) print() - ф-ция вывода информации на экран
2) input() - функция ввода данных с клавиатуры
3) int() - приводит значение к целому числу, отбрасывает дробную часть
4) float() - приводит значение к вещественному числу
5) str() - преобразует любой объект в строковый тип данных
6) bool() - приводит значение к логическому типу(True/False)
7) type() - возвращает тип переданного объекта
8) len() - возвращает длину последовательности(строки, списка, кортежа)
9) None - спецальный объект, обозначающий отсутствие значения
10) переменная - именованный контейнер для хранения данных
11) комментарий # - текст после символа #, который интерпритатор игнорирует
12) + - * / // % ** - арифметические операторы: сложение, вычитание, умножение, деление, целочисленное деление, остаток от деления,возведение в степень
13) == != > < >= <= - операторы сравнения. Возвращают true или false
14)  and or not - логические операторы: "и", "или", "не"
15) import - ключевое слово для подключения внешних модулей и библиотек
16) f-string - форматированные строковые литералы. Позволяют вставлять переменные и выражения прямо в строку через {}
